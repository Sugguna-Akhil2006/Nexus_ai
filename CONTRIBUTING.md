# Contributing to Nexus AI

We welcome contributions to Nexus AI!

## Code Contributions

1. **Fork** the repository and create your branch from `main`.
2. **Coding Standards**:
   - Write clean, documented Python code matching Google python style guides.
   - Run tests before submitting a Pull Request.
3. **Submit PR**: Open a pull request against the `main` branch. Provide a detailed summary of changes.
